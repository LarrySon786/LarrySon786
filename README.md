# Brandon Richards

## Hello! 👋

I'm Brandon Richards, a software development student at Brigham Young University–Idaho with a focus on C#, .NET, and backend development. I enjoy building practical applications that solve real-world problems. Welcome to my profile!

## Portfolio Projects

- [Electronic Medical Record](https://github.com/LarrySon786/electronic-medical-record-senior-project): This project is an employee application for a healthcare practice. It allows for several features including login, patient data management, scheduling, employee chat rooms, patient charting, and employee administration management. It was built using .NET and the Blazor framework as a team project in my senior year of college. I was the team lead for this project and designed several aspects of the software including the authentication workflow, database design, scheduling features, patient charting features, and parts of the patient data features. It was built in about a 4-week period during school.
- [Student Portal (In-Progress Project)](https://github.com/LarrySon786/StudentPortalPracticeTwo): This project features a student portal for a university. It allows students, instructors, and administrators to log in to the system to handle class registrations, grades, assignments, creation of new programs, and more. This project was my major independent software project. This project helped me turn concepts learned in the classroom into practical software development skills. I learned to create authentication / authorization systems, use dependency injection, build service layers, understand database connections and lifetimes, create complex model integrations, build UI components, and much more.
